# JacXson U70：飞机发动机拆装车的电机选型验证

## 概述

JacXson U70 是法国 EXCENT 集团（图卢兹）设计的精密电动拆装车，用于窄体客机（A220/A320/B737/E-Jet）的发动机安装与拆卸。它用单人遥控电动平台取代了传统方式——悬挂在脚手架上的手动链条葫芦、多名操作员协同作业。本文聚焦于**通过动能定理验证电动缸电机选型**：建立举升机构的等效惯量模型，计算启动峰值转矩和循环热等效转矩，并对照电机规格进行双重验证。核心洞察是：**电机选型不由峰值负载单独决定**——重复工作循环施加的热约束往往才是最终拍板的因素。

---

## 1. 系统背景

### 维护痛点

发动机大修是航空公司的主要运营成本之一（约占总运营支出的 10%）。每 6–7 年，每台发动机需要深度大修，涉及从飞机上完整拆卸。传统流程：在发动机短舱周围搭建脚手架 → 悬挂链条葫芦 → 多名操作员手动协同升降 → 重达数吨的发动机需与安装点精确对准。

**慢、危险、易损伤数百万美元的发动机。**

### JacXson U70 方案

- 两副可调间距横梁 + 叉式接口——适应不同发动机托架
- 四组独立电动缸举升臂——实现俯仰、滚转和垂直升降的精确控制
- 后轮驱动+转向、前轮转向——全向移动，精确就位
- 触摸屏遥控——单人操作

**EXCENT 声称的优势：** 显著节省时间成本、大幅提升操作安全性与人机工效、极大降低发动机损伤风险、大幅减少所需工具种类。

## 2. 系统架构

### 举升机构

每组举升臂由三个刚体组成：

- **底盘（0）：** 固定参考系
- **副臂（1）：** $m_1 = 135$ kg，绕 O 点转动，质心距 $a_1 = 430$ mm
- **主臂（2）：** $m_2 = 180$ kg，绕 B 点转动，质心距 $a_2 = 236$ mm
- **发动机负载：** 集中质量 $M_{ch} = 1750$ kg，作用于 C 点（叉式接口）

臂段长度 $L = OB = AB = BC = 850$ mm。

### 电动缸架构

```
┌──────────────────────────────────────┐
│         电动缸（Vérin Électrique）     │
│  ┌──────────┐ ┌────────┐ ┌────────┐  │
│  │ 直流电机  │→│ 减速器  │→│ 滚珠丝杠│  │
│  │ + 制动器  │ └────────┘ └────────┘  │
│  └──────────┘        ↓               │
│              活塞杆（4）相对缸体（3）平移  │
└──────────────────────────────────────┘
```

制动器为**失电制动**（frein à manque de courant）——断电即抱死，防止发动机坠落。这是关键安全特性。

## 3. 动能定理：电机转矩模型

### 为什么用能量法？

对于几何构型随时间变化的多体机构（举升过程中臂角 $\theta(t)$ 持续改变），动能定理（TEC）提供了比 Lagrange 方程更简洁的能量方法：

$$\frac{d}{dt}T_{\Sigma/0} = \sum P_{ext} + \sum P_{int}$$

### 能量组成

总动能分解为四项：

$$T_{\Sigma/0} = \underbrace{T_{1/0}}_{\text{副臂}} + \underbrace{T_{2/0}}_{\text{主臂}} + \underbrace{T_{M_{ch}/0}}_{\text{发动机负载}} + \underbrace{T_{mot/0}}_{\text{电机转子}}$$

每项表达为 $\frac{1}{2} J_i \dot{\theta}^2$（或折算到电机轴 $\frac{1}{2} J_i \omega_m^2$），其中 $J_i$ 是**折算到电机轴的等效惯量**。

### 等效惯量——核心概念

变化几何意味着等效惯量是**构型相关**的：

$$J_\Sigma(t) = J_1 + J_2(\theta(t)) + J_{M_{ch}}(\theta(t)) + \frac{J_m}{k^2(t)}$$

其中 $k(t) = \dot{\theta}(t)/\omega_m(t)$ 是臂角速度与电机角速度之间的运动学比——同一电机转速在不同臂角下产生不同的臂速。

### 功率平衡

电机转矩 $C_m(t)$ 必须克服三个分量：

$$C_m(t) = \underbrace{J_\Sigma(t) \frac{d\omega_m}{dt}}_{\text{加速项}} + \underbrace{\frac{1}{2} \frac{dJ_\Sigma(t)}{dt} \omega_m(t)}_{\text{变惯量项}} - \underbrace{C_{pes}(t)}_{\text{重力项}}$$

- **加速项：** 惯性转矩——启动和变速时占主导
- **变惯量项：** 因 $J_\Sigma$ 随臂角变化——即使恒速，变化几何也需额外转矩
- **重力项：** 1750 kg 发动机负载产生位置相关的重力转矩

## 4. 电机验证：双重约束

### 峰值转矩（启动）

$t = 0$ 时，臂处于最低位置（$\theta$ 接近最大），从静止加速：

$$C_m(0) = J_\Sigma(0) \cdot \frac{d\omega_m}{dt}\bigg|_{t=0} - C_{pes}(0)$$

重力项在最低位置时最大（最长力臂），加速需克服全系统的静态惯量。仿真曲线显示**启动转矩显著高于恒速转矩**——证实加速和变惯量项在瞬态中占主导。

### 热等效转矩（工作循环）

重复举升循环中，电机发热升温。**热等效转矩** $C_{th}$ 用 RMS 方式捕捉变化转矩曲线的平均效应：

$$C_{th} = \sqrt{\frac{\sum T_i C_i^2}{T_{cycle}}}$$

其中 $T_i$ 为时间间隔，$C_i$ 为对应的转矩值。

```python
def Ctherm(C, t):
    total = 0.0
    for i in range(len(t) - 1):
        dt = t[i+1] - t[i]
        C_avg_sq = ((C[i] + C[i+1]) / 2) ** 2
        total += dt * C_avg_sq
    return (total / (t[-1] - t[0])) ** 0.5
```

**执行结果：$C_{th} = 2.34$ N·m**

### 双重约束条件

电机**额定转矩**必须 $> 2.34$ N·m，且**峰值转矩**必须 $>$ 工作循环中最大 $C_m(t)$。只满足一个约束的电机是不可接受的。

---

## 5. 核心 Tradeoff：电机选型是热问题

### 为什么峰值转矩不够

最直接的思路是算出最大所需转矩，选一台额定值匹配的电机。但电机可以在短时间内提供**远超连续额定值的峰值转矩**——真正的限制是热。

- **简单选型：** 计算 $\max C_m$ → 选 $C_{nom} > C_{max}$ 的电机 → 结果：电机偏大、偏重、偏贵
- **热选型：** 计算 $C_{th}$ → 选 $C_{nom} > C_{th}$ 的电机 → 验证峰值在过载能力范围内 → 结果：更轻、更便宜、经过验证

### 适用范围

这一模式适用于**任何有重复工作循环的驱动系统**——机器人、机床、输送系统、电动汽车。电机的连续（热）额定值是约束边界；峰值额定值仅为瞬态提供余量。

对于 JacXson U70，典型工作循环包括：接近飞机（低转矩）→ 接合发动机托架（中等转矩）→ 举升发动机（高转矩——重力+加速）→ 放下并撤离（中等转矩）→ 重复。

热等效转矩将整个曲线积分为一个设计验证值。

## 6. 工程结论

本分析展示了从第一性原理出发的**机电系统验证完整流程**：

1. 系统分解——识别刚体、铰链、自由度
2. 运动学建模——以广义坐标表达速度
3. 能量法动力学——用动能定理替代完整 Lagrange 方程，简洁且等价
4. 电机转矩分解——分离加速、构型相关惯量和重力三个分量
5. 双重验证——峰值转矩（瞬态）+ 热转矩（工作循环）对照电机规格

### 四篇分析的总览

| 分析 | 系统 | Tradeoff | 领域 |
|------|------|---------|------|
| 起落架 | 被动减震器 | 冲击吸收 vs. 振动隔离 | 物理 / 机械 |

| DELTA | 伺服夹具轴 | 稳定性 vs. 精度 vs. 快速性 | 控制 / 机器人 |
| **JacXson** | **发动机拆装车** | **峰值转矩 vs. 热转矩** | **机电 / 能量** |

## 附录：动能定理推导

### A.1 副臂动能

副臂绕 O 点以角速度 $\dot{\theta}$ 旋转：$T_{1/0} = \frac{1}{2} C_1 \dot{\theta}^2$，其中 $C_1 = 3.5 \times 10^7$ kg·mm²

### A.2 主臂动能

主臂同时平动和转动，其质心速度和角速度均随 $\theta$ 和 $\dot{\theta}$ 变化，等效惯量 $J_2(t)$ 是构型相关的。

### A.3 发动机负载动能

发动机建模为 C 点集中质量 $M_{ch} = 1750$ kg：$T_{M_{ch}/0} = \frac{1}{2} J_{M_{ch}}(t) \dot{\theta}^2$

### A.4 总等效惯量

叠加并折算到电机轴：$J_\Sigma(t) = J_1 + J_2(t) + J_{M_{ch}}(t) + J_m/k^2(t)$

电机转矩由功率平衡导出，见第 3 节。
