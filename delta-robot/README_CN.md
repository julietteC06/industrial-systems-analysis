# DELTA 机器人夹具旋转轴：稳定性-精度-快速性三难困境

## 概述

DELTA 并联机器人使用嵌套伺服控制架构——内环速度反馈 + 外环位置反馈——在三维空间中精确控制工具朝向。本文建立直流电机模型，推导开环传递函数，设计比例控制器以满足性能指标。核心洞察是经典控制工程中的**稳定性-精度-快速性三难困境**：增大控制器增益可以提升精度（减小静差）和快速性（增大带宽），但同时侵蚀稳定性裕度。工程师的任务是找到三者共存的增益区间——或者在比例控制器力不能及时引入更高级的校正器（PI、超前校正）。

---

## 1. 系统背景

### DELTA 机器人

DELTA 是并联臂机械手，广泛用于高速拾放作业——电子装配、食品包装、药品分拣。三组平移臂在 XYZ 方向定位平台，**第四轴**——穿过中心的双万向节伸缩轴——控制夹具绕垂直轴的旋转。

### 级联控制架构

```
用户输入 θ_c → 角度-电压转换 K_pot → 比较器 →
    位置控制器 C(p) → 比较器 → 放大器增益 A → 直流电机 H_m(p) →
    减速器 1/N → 万向节 T(p)=1 → 输出 θ_p

    测速发电机 K_ω ← 电机转速 Ω_m → 积分器 1/p →
        编码器+数模转换 K_pos → 反馈回比较器
```

- **内环（测速环）：** 速度反馈——稳定电机、增加阻尼
- **外环（位置环）：** 角度位置反馈——保证零静差和跟踪精度

### 性能指标

| 要求 | 判据 | 目标 |
|------|------|------|
| 稳定性 | 相位裕度 $M_\varphi$ | $\geq 45°$ |
| 稳定性 | 增益裕度 $M_G$ | $\geq 10$ dB |
| 精度 | 静态误差 $\varepsilon_s$ | $= 0$ |
| 快速性 | 0 dB 带宽 $\omega_0$ | $\geq 50$ rad/s |

## 2. 直流电机建模

### 物理方程

**电气：** $U_m(t) = e(t) + R \cdot i(t) + L \cdot \frac{di(t)}{dt}$

**机电耦合：** $e(t) = K_e \cdot \omega_m(t)$，$C_m(t) = K_c \cdot i(t)$

**机械：** $J \cdot \frac{d\omega_m(t)}{dt} = C_m(t)$

### 数值参数

| 参数 | 符号 | 数值 | 单位 |
|------|------|------|------|
| 反电势常数 | $K_e$ | 0.0143 | V/(rad/s) |
| 转矩常数 | $K_c$ | 0.137 | N·m/A |
| 电枢电阻 | $R$ | 1.0 | Ω |
| 电枢电感 | $L$ | 1.65×10⁻³ | H |
| 转动惯量 | $J$ | 12×10⁻⁵ | kg·m² |
| 减速比 | $N$ | 0.2 | — |
| 测速机增益 | $K_\omega$ | 0.006 | V/(rad/s) |
| 位置传感器 | $K_{pos}$ | 0.01 | V/rad |

### 电机传递函数

拉普拉斯变换后消去 $i(t)$：

$$H_m(p) = \frac{\Omega_m(p)}{U_m(p)} = \frac{K_c}{K_e K_c + R J p + L J p^2}$$

电气时间常数 $\tau_e = L/R = 1.65$ ms 远小于机械动态——电机近似一阶系统。

---

## 3. 测速内环

测速发电机测量电机转速 $\omega_m(t)$ 并按比例反馈电压 $U_\omega(t) = K_\omega \cdot \omega_m(t)$。内环的作用：
- 增加位置环的等效阻尼
- 降低对电机参数变化的敏感度
- 线性化电机响应

放大器增益 $A$ 按最小 5% 建立时间选取——增益越高，响应越快，但噪声敏感度和饱和风险也增大。

---

## 4. 位置环：未校正分析

### 开环传递函数

内环闭合、取 $C(p) = 1$（无校正），化简后：

$$FTBO(p) = \frac{\alpha}{p(103 + 3.2 \times 10^{-3} p + 5.3 \times 10^{-6} p^2)}$$

### 性能诊断

| 指标 | 未校正值 | 要求 | 状态 |
|------|---------|------|------|
| 相位裕度 | $\ll 45°$ | $\geq 45°$ | ❌ 不达标 |
| 增益裕度 | 低 | $\geq 10$ dB | ❌ 不达标 |
| 带宽 | $\ll 50$ rad/s | $\geq 50$ rad/s | ❌ 不达标 |
| 静态误差 | 0（1 类系统） | 0 | ✅ |

未校正系统不稳定或严重欠阻尼。**精度是唯一合格的指标**——但那是因为积分器天然保底，不是系统设计得好。

## 5. 比例校正：寻找可行区间

### 三难困境的数学表达

比例控制器 $C(p) = K_p$ 将 Bode 幅值曲线垂直平移而不改变相位：

- **增大 $K_p$：** 幅值上升 → 带宽增大（快速性 ↑）→ 低频增益增大（精度 ↑）→ 但 0 dB 交点右移到相位滞后更大的频段 → **稳定裕度 ↓**
- **减小 $K_p$：** 幅值下移 → 稳定裕度 ↑ → 但带宽缩小（快速性 ↓）

### 确定 $K_p$ 可行区间

$K_p$ 需同时满足两个不等式：

1. **带宽约束（下界）：** $K_p \geq K_{p,min}$ 使得 $\omega_{0dB} \geq 50$ rad/s
2. **稳定性约束（上界）：** $K_p \leq K_{p,max}$ 使得 $M_\varphi \geq 45°$

若 $K_{p,min} > K_{p,max}$，则比例控制器**无法**单独满足所有指标，需引入更高级的校正器。

### 校正器升级路径

| 校正器 | 作用 | 适用场景 |
|--------|------|---------|
| P（比例） | 增益缩放 | 裕度已充足，仅需更大带宽 |
| PI（比例-积分） | 零静差 + 提升低频增益 | 精度是瓶颈 |
| 超前校正 | 在穿越频率附近提升相位 | **相位裕度是瓶颈——本系统最可能需要** |

---

## 6. 三难困境的普适意义

$$\text{稳定性} \uparrow \iff \text{精度} \downarrow \text{ 且 } \text{快速性} \downarrow$$

- 增大增益 → Bode 幅值曲线上移 → 0 dB 交点右移 → 穿越频率处相位滞后更大 → 相位裕度降低（稳定性 ↓）
- 但更高的增益 → 低频幅值更大 → 环路增益更大 → 误差更小（精度 ↑）
- 同时更高的增益 → 带宽扩展（快速性 ↑）

这不是设计缺陷——这是使控制工程成为一门设计学科（而非纯粹数学）的根本约束。

## 7. 工程结论

DELTA 机器人夹具轴是一例清晰的**级联伺服控制**——这种架构广泛用于机器人、数控机床、天线跟踪等定位系统。本分析展示：

1. 嵌套环（速度内环 + 位置外环）如何将复杂控制问题分解为可管理的层次
2. 如何从物理参数推导电机传递函数
3. 如何从 Bode 图读取稳定性、精度和快速性
4. 比例校正如何平移性能平衡——以及为什么有时不够用
5. 如何判断何时需要超前校正

## 附录：数学推导

### A.1 电机传递函数

由电气方程 + 机械方程消去电流：$\boxed{H_m(p) \approx \frac{1/K_e}{1 + \frac{RJ}{K_e K_c}p}}$（$L \ll R$）

### A.2 内环闭环传递函数

$$FTBF_{inner}(p) = \frac{A \cdot H_m(p)}{1 + A \cdot H_m(p) \cdot K_\omega p}$$

### A.3 位置开环传递函数

$$FTBO(p) = \frac{K_{pos}}{p} \cdot FTBF_{inner}(p) \cdot \frac{1}{N}$$

1 类系统——-20 dB/dec 低频斜率保证阶跃指令下零静差。
