# eTras：全球首套全电动反推力装置——为什么要将液压系统从发动机短舱中移除？

## 概述

Safran 公司的 eTras（Electrical Thrust Reverser Actuation System）是商用航空领域首套全电动反推力驱动系统。它用一台 25 kW 直流电机驱动四组同步滚珠丝杠，通过柔性轴传输动力，取代了传统的液压回路——液压泵、流体管路、作动器。本文分析**液压转电动的决策逻辑**，建立电机控制模型，设计 PI 电流控制器，并评估工程 tradeoff：重量、可靠性、维护成本和精度的权衡。核心洞察是：转向电动的决策不只是性能考量——更是**系统级优化**，驱动力来自在一个火灾高风险的发动机区域中消除故障多发的液压基础设施。

---

## 1. 系统背景

### 什么是反推力装置？

飞机着陆时需要从 ~250 km/h 减速至滑行速度。机轮刹车承担大部分工作，但**反推力装置**通过将发动机外涵气流向前折转提供额外制动力。

当反推力装置展开时：
- 平移整流罩向后滑动
- 阻流门转入外涵道
- 叶栅暴露，将气流导向前方

机构必须平稳、同步地平移短舱外部结构——这就是 eTras 要解决的驱动问题。

### 为什么是安全关键系统

反推力装置**绝不允许**在空中意外展开，同时必须在着陆时可靠展开（即使单故障条件下）。驱动系统安装在发动机短舱内——极端振动、温度循环和火灾风险的环境。这一背景定义了所有工程决策。

---

## 2. 创新：电动驱动

### 传统方案：液压系统

- 高压液压油（~3000 psi / 207 bar）
- 液压管路穿过短舱到达作动器
- 液压作动器驱动平移整流罩
- 伺服阀控制流量

### 新方案：eTras 电动架构

```
TRCU（反推控制单元）→ 24V DC → 直流电机（25 kW）
    → 4× 柔性轴 → 4× 滚珠丝杠 → 平移整流罩 → 阻流门（运动链联动）

传感器反馈：
    → 增量编码器 → 电机轴角位置
    → 4× RVDT → 四组丝杠同步校验
```

**核心组件：**
- **TRCU**（反推力控制单元）：功率电子 + 控制器，将 115V AC（360–800 Hz，来自发动机发电机）转换为 24V DC
- **单台 25 kW 直流电机**：唯一的原动机
- **4 根柔性轴**：柔性旋转轴，适应短舱几何形状和振动
- **4 组滚珠丝杠**：旋转运动 → 整流罩平移
- **增量编码器**：电机轴角位置反馈
- **4 个 RVDT 传感器**（旋转可变差动变压器）：验证四组丝杠同步

### 架构决策

从短舱中移除液压系统意味着：
- 发动机热区附近无可燃液压油 → **降低火灾风险**
- 无高压管路泄漏风险 → **提高可靠性**
- 无液压泵负载发动机 → **节省燃油**
- 更轻的系统 → **减重**（电动执行器功率重量比更优）

## 3. 直流电机建模

### 物理模型

直流电机由三组方程描述，耦合电气域和机械域：

**电气方程：** $u(t) = e(t) + R \cdot i(t) + L \cdot \frac{di(t)}{dt}$

**机电耦合：**
$C_m(t) = K_m \cdot i(t)$（转矩正比于电流）
$e(t) = K_m \cdot \omega_m(t)$（反电动势正比于转速）

**机械方程（PFD）：** $J_m \cdot \frac{d\omega_m(t)}{dt} = C_m(t) - C_r(t)$

关键参数：$u$ 端电压，$i$ 电枢电流，$R, L$ 电阻和电感，$K_m$ 转矩/反电势常数，$C_m$ 电磁转矩，$C_r$ 负载转矩，$\omega_m$ 角速度，$J_m$ 等效转动惯量。

---

## 4. 电流伺服环（转矩控制）

### 为什么要控制电流？

$C_m = K_m \cdot i(t)$ ——控制电流就是控制转矩。电流伺服环确保：精确的滚珠丝杠力输出、过流保护、对整流罩气动负载扰动的抑制。

### 控制架构

电流设定值 $I_c$ → 比较器 → PI 控制器 $C(p)$ → 适配器 $K_a$ → 电机（锁转） → 电流传感器 $R_e$ 反馈回比较器

适配器增益设为 $K_a = R_e$，使得 $i(t) = i_c(t)$ 时误差为零。

### 开环传递函数（锁转）

锁转条件下（$C_r = 0$, $\omega_m = 0 \implies e = 0$），电气动态简化为一阶系统：

$$FTBO(p) = \frac{K_a \cdot C(p) \cdot R_e}{R + Lp}$$

时间常数 $\tau_e = L/R$ 是限制带宽的电气极点。

---

## 5. PI 控制器设计

### 为什么用 PI？

$$C(p) = K_p \cdot \frac{1 + \tau_i p}{\tau_i p}$$

- **比例作用** $K_p$：设定响应速度
- **积分作用** $1/\tau_i p$：保证**零稳态误差**——电流精确跟踪设定值

### 极点补偿策略

PI 控制器调谐为**消去电气极点**：

$$\tau_i = \tau_e = L/R$$

补偿后的开环传递函数为纯积分器：

$$FTBO(p) = \frac{K_{BO}}{p}$$

——无穷大直流增益（零误差），-20 dB/dec 斜率，全频段 -90° 相位。$K_p$ 随后根据期望带宽选取。

## 6. 核心 Tradeoff：液压 vs. 电动驱动

| 评估维度 | 液压 | 电动（eTras） |
|---------|------|-------------|
| 重量 | 更重（泵 + 油液 + 管路） | 更轻（更好的功率重量比） |
| 可靠性 | 较低（泄漏、油液污染敏感） | 较高（更少泄漏点、无污染物） |
| 功率密度 | **更高**（~3 kW/kg / 作动器） | 较低但在持续提升 |
| 控制精度 | 成熟伺服阀技术 | **更优**——通过电流环直接转矩控制 |
| 火灾安全 | 可燃油液在热短舱中 | **更安全**——无可燃液体 |
| 维护成本 | 更高（密封更换、油液维护） | 更低（无需液压油、更少磨损件） |
| 系统复杂度 | 更少零件但基础设施重 | 更多电子但安装更简单 |

### 决定性因素：火灾安全

在短舱环境中，火灾安全是首要的。液压油（Skydrol 等）在发动机火灾条件下可燃。**将其从短舱中移除不是增量改进——而是消除了一整个危险类别。** 这一因素使电动架构在战略上占优。功率密度的差距正在缩小，且对于反推这一应用场景（每次飞行仅几秒部署），25 kW 配合适当尺寸的电机完全足够。

---

## 7. 工程结论

eTras 体现了航空业更广泛的趋势：**多电飞机（More Electric Aircraft, MEA）**。反推力装置成为合理的电动化目标，因为：
1. 间歇运行（非连续工作制）
2. 短舱是火灾关键区——液压油是隐患
3. 电控实现更精密的四丝杠同步
4. 单电机 + 柔性轴架构优雅地解决了几何约束

### 销售工程师视角

> "是的，电驱动系统是一项新技术，服役历史较短。但它消除了您的短舱中最大的单一火灾风险，每台发动机减掉约 40 kg 液压基础设施，且通过免去液压油维护缩短了周转时间。PI 电流控制环意味着系统能在部件寿命期内自适应磨损——不像液压伺服阀那样需要定期重新标定。"

**这就是将工程分析翻译为客户价值。** 本文的建模和推导是基础；用商业语言清晰表达 tradeoff 才是核心能力。

## 附录：数学推导

### A.1 直流电机传递函数

由电气方程 + 机械方程消去 $I(p)$：

$$\boxed{H_{UI}(p) = \frac{J_m p}{J_m L p^2 + J_m R p + K_m^2}}$$

### A.2 适配器增益

稳态时 $i = i_c$：$\varepsilon_U = K_a i_c - R_e i = (K_a - R_e)i_c$

令 $\varepsilon_U = 0$：$\boxed{K_a = R_e}$

### A.3 PI 极点补偿

锁转 + PI 控制器，取 $\tau_i = L/R$ 消去电气极点：

$$FTBO(p) = \frac{K_{BO}}{p}$$

——纯积分器，保证零稳态误差（1 类伺服），-90° 相位裕度。
